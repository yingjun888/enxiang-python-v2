先學一個方法：不要猜輸出，跟著電腦走

看到 Python 程式時，先不要急著想答案。每執行一行，就問自己三件事：現在有哪些資料？這一行改了什麼？下一行看到的是改過後的什麼？

一句話記：Python 不會「想」，只會照順序執行。你也照順序追，就比較不會猜錯。

第 1 章｜String 字串

重點：索引、切片、len、字串不可直接改某一格。

1. 索引：電腦從 0 開始數

s = "Python"
print(s[2])
P y t h o n
0 1 2 3 4 5
先建立字串 Python。
s[2] 找 index 2，所以拿到 t。

輸出：t

容易錯：把 index 2 當成「第 2 個字」。Python 的第一格是 index 0，所以第 3 個字才是 index 2。
一句話記：索引從 0 開始。

2. 切片：左邊拿，右邊不拿

s = "Python"
print(s[1:4])
P y t h o n
0 1 2 3 4 5
從 index 1 開始：y。接著 t、h。到了 index 4 就停止，4 本身不拿。

輸出：yth

容易錯：以為 1:4 包含 index 4，所以寫成 ytho。
一句話記：[開始:結束]＝左邊拿，右邊不拿。

3. len() 算的是「有幾個」

word = "apple"
print(len(word))
a、p、p、l、e，一共 5 個字元，所以 len(word) 是 5。注意：最後一個 index 是 4，但長度是 5。
一句話記：len 是數量；index 是位置。長度 5 的字串，最後位置是 4。

4. String 不能直接改其中一格

s = "cat"
s[0] = "b"
第二行想把 c 直接改成 b，但 Python 的 string 是 immutable（不可變物件），不能用索引直接改某一個字元。
s = "cat"
s = "b" + s[1:]
print(s)

先取出 s[1:] 得到 at，再建立新的字串 bat，最後讓 s 指向新字串。

一句話記：String 可以做出新的，但不能直接改原本某一格。

第 2 章｜List 串列

重點：List 可以改、append 會改原 List、索引與切片規則和 String 很像。

1. List 可以直接修改某一格

a = [10, 20, 30]
a[1] = 99
print(a)
建立 [10,20,30] → index 1 是 20 → 把這一格改成 99 → 原本的 a 已經變了。

[10, 99, 30]

一句話記：String 某一格不能直接改；List 某一格可以改。

2. append() 是加到原 List 最後面

a = [10, 20]
a.append(30)
print(a)
執行前：a → [10,20]
append(30) 後：a → [10,20,30]
a = [10, 20]
a + [30]
print(a)

這一版最後仍是 [10,20]。因為 a + [30] 產生了新 List，但沒有把新結果存回 a。

一句話記：append 直接改原 List；+ 產生新 List。

3. remove() 和 pop() 不要混

a = [10, 20, 30]
a.remove(20)
remove(20) 是找「值 20」並移除它。若是 pop(1)，1 是位置 index，會移除 index 1 的元素並回傳它。
一句話記：remove 看「值」；pop 看「位置」。

第 3 章｜file mode 檔案模式

重點：r / w / a 不是三個英文單字而已，要看「原檔案會發生什麼事」。

1. r = read：只讀

f = open("note.txt", "r")
text = f.read()
f.close()
打開 note.txt → 讀內容 → 存到 text → 關檔。原本檔案內容不因為 read 被改掉。
r：我要讀，原資料保留。

2. w = write：重新寫

假設 note.txt 原本是：

apple
banana
f = open("note.txt", "w")
f.write("cat")
f.close()
用 w 開啟既有檔案時，原內容會被截斷；寫入後內容成為：
cat
這是最需要小心的模式：不是「在後面寫」，而是準備重寫。
w：重寫；舊內容可能消失。

3. a = append：接在最後

同樣假設原檔案有 apple、banana：

f = open("note.txt", "a")
f.write("\ncat")
f.close()
原內容保留，cat 接到最後。
apple
banana
cat
a：追加；舊內容留下來。

4. 三個模式放在一起看

r：讀，不負責新增內容。
w：重新寫，既有內容可能被清掉。
a：在最後追加，既有內容保留。

一句話記：r 讀、w 重寫、a 往後加。先想「舊資料要不要保留」，再選模式。

第 4 章｜Sequential Search 循序搜尋

重點：不要先背程式。先理解「從第一個開始，一個一個比較」。

1. 人怎麼找，電腦就怎麼找

在 [8, 3, 12, 5, 9] 中找 5：

8 ✗ → 3 ✗ → 12 ✗ → 5 ✓ → STOP

這就是 sequential search。它沒有瞬間知道 5 在哪裡，而是照順序檢查。

一句話記：從頭開始，一個一個比，找到就停。

2. 把人的動作翻成 Python

nums = [8, 3, 12, 5, 9]
target = 5

for x in nums:
    if x == target:
        print("found")
        break
x=8 → 不是 5，繼續。
x=3 → 不是 5，繼續。
x=12 → 不是 5，繼續。
x=5 → 相等，印 found → break 結束迴圈。
break 的意思：已經找到，不需要繼續找後面的資料。

3. 如果題目要的是「位置」

nums = [8, 3, 12, 5, 9]
target = 5

for i in range(len(nums)):
    if nums[i] == target:
        print(i)
        break
i 代表位置：0、1、2、3……
nums[i] 才是那個位置裡面的值。當 i=3 時，nums[3]=5，所以輸出 3。
容易錯：把 i 和 nums[i] 當成同一件事。i 是「位置」；nums[i] 是「那個位置的資料」。
一句話記：i 是格子號碼；nums[i] 是格子裡的東西。

4. 沒找到時，為什麼要用 found？

nums = [8, 3, 12]
target = 5
found = False

for x in nums:
    if x == target:
        found = True
        break

if found:
    print("找到")
else:
    print("沒找到")
一開始先假設沒找到：False。只有真的遇到 target 才改成 True。整個搜尋結束後，再看 found 的狀態決定輸出。
一句話記：found 像一面旗子；找到就把旗子從 False 翻成 True。

最後只記這 8 句

① index 從 0 開始。
② slice 左邊拿、右邊不拿。
③ len 是數量，不是最後一個 index。
④ String 不能直接改某一格，List 可以。
⑤ append 會改原 List。
⑥ r 讀、w 重寫、a 追加。
⑦ Sequential Search 從頭一個一個找。
⑧ i 是位置，list[i] 是位置裡的資料。
