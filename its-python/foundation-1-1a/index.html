變數與指派

x = 10

= 是「指派」：把右邊的值交給左邊名稱 x。後面若寫 x = "Hi"，x 的值與型別就改變了。

先掌握四種基本型別

a = 10       # int 整數
b = 10.0     # float 浮點數
c = "10"     # str 字串
d = True     # bool 布林值

先看有沒有引號、有沒有小數點。10、10.0、"10"的型別不同。

type() vs print()

x = 7
print(x)        # 7
print(type(x))  # <class 'int'>

type() 取得型別；print() 顯示結果。英文 value 是值，output 是輸出。
