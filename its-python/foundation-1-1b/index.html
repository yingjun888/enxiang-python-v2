變數重新指派與複製目前值

a = 6
b = a
a = 10
print(b)      # 6

第二行的 b 取得當時的整數 6；第三行改寫 a，不會連帶把 b 改成 10。

新增基本資料型別

a = None       # NoneType
b = [1, 2]     # list
c = (1,)       # tuple
d = {"x": 1}   # dict
e = {1, 2}     # set

(1) 不是 tuple，(1,) 才是；{} 是空 dict，空 set 用 set()。

只判斷 /、// 的結果與型別

print(8 / 4)       # 2.0
print(8 // 3)      # 2
print(8.0 // 3)    # 2.0

/ 會得到 float；此處的 // 若包含 float 運算元，結果仍是 float。本回不考負數取整等後續運算子細節。
