先學三個小觀念

① Indexing 索引

索引從 0 開始，[-1] 是最後一個字元。索引越界會出現 IndexError。

s = "MANGO"
s[0]    # 'M'
s[-1]   # 'O'
② Slicing 切片：s[start:stop:step]

頭包尾不包。省略 start 從頭取；省略 stop 取到最後；step 為 2 表示隔一個位置取字元，-1 表示反向。

s = "MANGO"
s[1:4]  # 'ANG'
s[:2]   # 'MA'
s[::2]  # 'MNO'
s[::-1] # 'OGNAM'
③ 容易混淆的越界

直接取 s[99] 會 IndexError；切片 s[99:] 得到空字串，不會報錯。
