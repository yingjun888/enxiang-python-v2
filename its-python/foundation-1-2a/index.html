① 看懂轉換函式，再開始測驗

型別轉換不是「查型別」；它會依函式建立或回傳轉換後的值。以下是教師講義中的概念範例。正式測驗使用不同數值和情境，作答時不顯示提示。

int / float / str

int(3.9)      # 3：去掉小數，不是四捨五入
int(-3.9)     # -3：往 0 方向截斷
int("42")     # 42
float("3.5") # 3.5
str(100)     # '100'
int("3.5")   # ValueError

bool：看值是否為「空」或「零」

bool(0)        # False
bool("")       # False
bool(" ")      # True：一個空白也是非空字串
bool("False")  # True：非空字串

round：剛好在 .5 時留意偶數捨入

round(2.5)   # 2
round(3.5)   # 4
